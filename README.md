# MailerSend Studio

A multi-channel messaging console for SMS, iMessage, and WhatsApp — built around the [MailerSend](https://www.mailersend.com/) API.

This is a personal working studio, not an SDK fork.

## What it does

- Compose and send SMS through MailerSend
- Route iMessage and WhatsApp alongside SMS in one console
- Keep channel status, contacts, and send history in one place

## Stack

React · TypeScript · TanStack Start · Vite · Tailwind · MailerSend Node SDK

## Note

API credentials are not stored in this repository. The studio expects them from the environment at runtime.
